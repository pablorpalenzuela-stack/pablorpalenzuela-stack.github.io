# Web personal — Pablo Rodríguez Palenzuela

## Descripción del proyecto
Web personal de Pablo Rodríguez Palenzuela, catedrático de la Universidad Politécnica de Madrid
y autor de divulgación científica. Generada con Hugo y el tema PaperMod, publicada en GitHub Pages.

Sustituye el blog anterior en WordPress (pablorpalenzuela.wordpress.com), cuyo contenido
se migrará a esta nueva web.

## Tecnologías
- Generador estático: Hugo
- Tema: PaperMod
- Despliegue: GitHub Pages
- Control de versiones: Git / GitHub

## Estructura de contenidos
- **Inicio** — presentación personal
- **Libros** — obras de divulgación científica
- **Artículos** — artículos y columnas publicados
- **Blog** — entradas propias, migradas desde WordPress

## Estilo y diseño
- Diseño limpio, tipografía legible
- Sin exceso de elementos decorativos

## Convenciones de escritura (español de España)
- Comillas tipográficas: «» (no "" ni '')
- Títulos y encabezados: solo mayúscula inicial (no Title Case)
- Idioma: español de España en todos los textos de la interfaz y el contenido

## Entorno de trabajo
- Sistema operativo: Windows 11
- Shell: PowerShell
- Editor: VS Code
- GitHub previsto: pablorpalenzuela (pendiente de confirmar al crear la cuenta)
- El usuario es programador experimentado en Python, pero no tiene experiencia previa
  con Hugo, Git ni GitHub
